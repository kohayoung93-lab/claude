# 재무상태표 대사용 계정별원장 생성 도구

`[재무상태표]`, `[계정]`(계정코드 ↔ 재무제표표시명 목록) 시트가 있는 템플릿
워크북과 ERP(이카운트)에서 받은 raw 원장 파일들로, 계정코드마다 "계정별원장"
시트를 하나씩 만들고 재무상태표 금액과 자동으로 대사(일치 여부 확인)해 주는
도구입니다.

`특수관계자 거래내역` / `ledger-tool-fill` / `ledger-tool-new`(거래처별계정별원장을
누적 워크북에 채워 넣는 도구들)와 달리, 이 도구는 **거래처별계정별원장이
아니라 재무상태표 검증용 계정별원장**을 만드는 용도입니다.

## 이 도구가 하는 일

1. `input_raw/`에 넣은 raw 원장 파일들을 파싱해서, 파일 안에 있는
   "계정별원장 / 코드(계정명)" 블록마다 계정코드를 기준으로 시트를 만듭니다.
2. `재무상태표` 시트의 F열(당기 금액)을 `=B+C` 수식으로 채워서, 뒤에 나오는
   재무제표 일치 여부 판정이 항상 이 합계값과 비교되도록 합니다.
3. `master/`에 넣은 템플릿의 `[계정]` 시트에 있는 계정코드 목록을 기준으로,
   raw가 있는 계정은 데이터를 채운 시트를, raw가 아직 없는 계정은 빈
   템플릿 시트를 만들어 둡니다 (나중에 3행부터 붙여넣기만 하면 됨).
4. 각 계정별원장 시트의 G1(계정코드)/H1(계정과목)/I1(Raw 마지막 잔액)/
   J1(재무제표 일치 여부, TRUE/FALSE)을 가벼운 INDEX/MATCH 수식으로
   고정해 둡니다 — 데이터 행 수가 바뀌어도 항상 정확한 값을 찾습니다.
5. `[계정]` 시트 C열(Raw유무)/D열(재무제표 일치)에 각 시트의 I1/J1을
   참조하는 수식을 넣고, "Raw없음"/`FALSE`는 빨간 글씨로 자동 강조합니다.
6. `[계정]` 시트가 맨 앞 탭으로 오도록 시트 순서를 정리합니다.

## 폴더 구조

```
계정별원장/
  input_raw/   raw 원장 xlsx 파일들을 넣는 곳 (파일명은 상관없음, 여러 개 가능)
  master/      [재무상태표], [계정] 시트가 포함된 템플릿 파일 1개
  output/      결과가 저장되는 곳 (템플릿 원본은 수정되지 않음)
  build_ledger.py    실제 처리 스크립트
  run_mac.command     macOS 더블클릭 실행용
  run_windows.bat     Windows 더블클릭 실행용
```

## 준비 (최초 1회)

다른 도구들과 동일합니다 — Python 설치 후 터미널에서:
```
pip3 install openpyxl
```

## 템플릿 파일 준비

`master/`에 넣을 템플릿 파일에는 다음 두 시트가 반드시 있어야 합니다.

- `재무상태표`: A열에 계정명, B열·C열에 당기 금액 구성값이 있는 시트.
  F열(당기 금액)은 도구가 실행할 때마다 `=B+C` 수식으로 자동으로 채워집니다
  (기존 F열 내용은 덮어씌워집니다).
- `계정`: `계정코드` / `재무제표표시명` 헤더가 있는 행부터, 그 아래로 전체
  계정코드·계정명 목록이 있는 시트.

`계정` 시트의 재무제표표시명과 `재무상태표` 시트 A열의 계정명을 매칭할 때,
스페이스·탭·줄바꿈·전각공백 같은 공백류 문자 차이는 무시합니다(공백을 전부
제거하고 비교). 공백이 아닌 글자 자체가 다르면(오타, 다른 표기 등) 여전히
매칭되지 않고 해당 시트 J1에 "재무상태표 미매칭"이 표시됩니다.

## 사용법

1. `input_raw/`에 raw 원장 파일들을 넣습니다 (여러 계정/여러 파일 한 번에
   가능, raw가 없는 계정은 빈 시트로 생성됩니다).
2. `master/`에 위에서 준비한 템플릿 파일 1개를 넣습니다.
3. `run_windows.bat`(Windows) 또는 `run_mac.command`(Mac)를 더블클릭합니다.
4. `output/`에 `{템플릿파일명}_계정별원장_날짜시간.xlsx` 파일이 생깁니다.
5. 터미널에 뜬 요약(총 계정 수 / Raw 있음·없음 / 경고)을 확인하세요.

## 확인하는 방법

- 결과 파일의 `계정` 시트에서 C열(Raw유무)/D열(재무제표 일치)에 빨간 글씨로
  강조된 항목이 있는지 먼저 확인하세요.
  - `Raw없음`: 아직 그 계정의 원장 데이터를 붙여넣지 않은 상태입니다.
  - `FALSE`: raw 원장의 잔액 합계와 재무상태표 금액이 다릅니다 — 해당
    계정 시트로 이동해(계정 시트의 셀을 클릭하면 바로 이동) I1(Raw 마지막
    잔액)과 J1 옆의 재무상태표 값을 비교해보세요.
- 이후 raw를 계속 업데이트할 때는 압축 파일을 다시 만들 필요 없이, 해당
  계정 시트의 3행부터 원장 데이터를 붙여넣기만 하면 I1/J1/`계정` 시트가
  자동으로 갱신됩니다.
- 콘솔에 아래 경고가 뜨면 사람이 직접 확인해야 합니다.
  - `[경고] 동일 계정코드가 여러 Raw 파일에 중복 존재`: raw 파일 여러 개에
    같은 계정코드가 있으면 나중 파일 값으로 덮어씁니다.
  - `[경고] [계정] 시트에 없는 계정코드가 Raw에 존재`: 템플릿의 `계정` 시트에
    등록되지 않은 계정코드가 raw에 있는 경우입니다.
  - `[주의] [계정] 시트에 같은 계정코드가 2번 이상 등장`: 유동/비유동처럼
    같은 계정명이 두 번 나오는 경우, 시트는 1개만 만들어지고 그중 "당기
    금액이 있는" 재무상태표 행 기준으로만 J1이 판정됩니다. 나머지 한쪽은
    직접 확인해야 합니다.
  - `[참고] 재무상태표에 동일 계정명이 여러 행 존재`: 위와 같은 이유로
    재무상태표 쪽에 이름이 중복된 경우, 당기 값이 있는 행을 자동으로
    채택했다는 안내입니다.
