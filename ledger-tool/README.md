# ERP 원장 → 특수관계자 거래내역 누적 도구

ERP(이카운트)에서 받은 "거래처별계정별원장" raw 파일을 정리해서,
누적 관리 중인 워크북(예: 특수관계자 거래내역)의 해당 회사 시트 맨 뒤에
자동으로 이어붙여 주는 도구입니다.

## 이 도구가 하는 일

1. raw 원장 파일(계정과목별로 블록이 반복되고 소계/합계/빈 줄이 섞인 원본 그대로)에서
   진짜 거래 내역만 뽑아냅니다.
   - "이월잔액" 행(기초 잔액 이월분)은 이미 기존 누적 데이터에 반영되어 있으므로 제외합니다.
     (12월 31일 결산 기준 이월잔액을 새로 반영해야 하는 특수한 경우는 이 도구가
     처리하지 않으니, 그럴 때는 직접 확인해서 넣어주세요.)
2. 계정코드를 `99.이카운트 계정과목표_HF` 매핑 시트에서 찾아 구분1·구분2를
   기존 파일과 똑같은 방식(수식)으로 채웁니다. 상대구분은 수기로 확인해야 하는
   항목이라 자동으로 채우지 않고 공란으로 남겨둡니다.
3. master 워크북의 대상 시트(예: HT) 맨 마지막 거래 행 바로 뒤에 새 거래를 끼워 넣고,
   `<차이내역>` 메모 블록은 그대로 아래로 밀어서 유지합니다.
4. 결과는 **원본을 덮어쓰지 않고** `output/` 폴더에 새 파일로 저장합니다.
5. 블록(계정)별로 "raw 파일의 합계 - 이월잔액 = 새로 담은 거래 합계"가 맞는지
   자동으로 검증해서 터미널에 보여줍니다.

## 폴더 구조

```
ledger-tool/
  input_raw/   raw 원장 xlsx를 넣는 곳 (파일명 = 시트명, 예: HT.xlsx → "HT" 시트)
  master/      누적 관리 중인 워크북 1개만 넣는 곳
  output/      결과가 저장되는 곳 (원본은 그대로 유지됨)
  append_ledger.py   실제 처리 스크립트
  run_mac.command     macOS 더블클릭 실행용
  run_windows.bat     Windows 더블클릭 실행용
```

## 최초 1회 준비 (컴퓨터에 Python 설치)

1. https://www.python.org/downloads/ 에서 Python 설치 (Windows는 설치 시
   "Add Python to PATH" 체크박스 꼭 체크)
2. 터미널(Mac: 터미널 앱 / Windows: cmd 또는 PowerShell)을 열고 아래 명령 실행:
   ```
   pip3 install openpyxl
   ```
   (Windows에서 pip3가 안 되면 `pip install openpyxl`)

## 매달 사용하는 법

1. `input_raw/` 폴더를 비우고, ERP에서 받은 raw 원장 파일을 넣습니다.
   - **파일 이름을 채워 넣을 시트 이름과 똑같이** 저장하세요. 예: HT 시트에 넣을
     거면 `HT.xlsx`로 저장.
   - 여러 회사를 한 번에 처리하려면 `HT.xlsx`, `HI.xlsx` 등 여러 개를 같이 넣어도 됩니다.
2. `master/` 폴더에 누적 관리 중인 워크북 1개를 넣습니다. (폴더에는 항상 1개만
   있어야 합니다)
3. `run_mac.command`(Mac) 또는 `run_windows.bat`(Windows)를 더블클릭합니다.
   - 터미널 창이 뜨고 처리 결과가 출력됩니다.
4. `output/` 폴더에 `원본이름_updated_날짜시간.xlsx` 파일이 생깁니다.

## 결과가 맞는지 확인하는 방법

**1) 터미널에 뜬 검증 리포트를 먼저 봅니다.**
   `계정블록 검증: 25/25 통과` 처럼 전부 통과했는지 확인하세요. 만약
   `[불일치]`가 뜨면 그 계정만 골라서 raw 파일과 output 파일을 직접 대조해봐야
   합니다 (숫자를 억지로 맞추지 않고, 안 맞으면 그대로 알려주도록 만들었습니다).

**2) output 파일을 열어서 눈으로 확인합니다.**
   - 해당 시트(예: HT)에서 새로 추가된 행들이 기존 마지막 거래 바로 다음에
     이어지는지 확인
   - 맨 아래 `<차이내역>` 메모 블록이 그대로 남아있는지 확인
   - 새로 추가된 몇 개 행의 "구분1", "구분2" 값이 계정과목표와 맞는지 확인
   - 엑셀에서 수식이 안 보이고 텍스트로 이상하게 보이면 `Ctrl+Alt+F9`
     (전체 재계산)을 한 번 눌러보세요.

**3) 다 확인됐으면, output 파일을 master 폴더의 원본 파일에 직접 덮어씌우세요.**
   이 도구는 절대 master 원본을 스스로 바꾸지 않습니다 — 확인 후 교체는
   사용자가 직접 하는 안전장치입니다.

## 다음 달에 다시 쓸 때

1. `input_raw/` 폴더를 비우고 새 raw 파일을 넣는다 (파일명 = 시트명)
2. `master/` 폴더의 파일을 지난달 확인 후 교체해둔 최신 누적 파일로 유지한다
3. 실행 파일 더블클릭
4. output 확인 후 master에 반영

## 알려진 제한사항 (1차 버전)

- 지금은 raw 파일 하나당 시트 하나(예: HT)를 대상으로 만들었습니다. 다른
  회사 시트(HI, HM, HD 등)도 같은 방식으로 파일명만 맞춰 넣으면 동작하도록
  설계했지만, 아직 HT로만 직접 확인했으니 다른 시트에 처음 쓸 때는 결과를
  한번 더 꼼꼼히 봐주세요.
- 시트 오른쪽에 있는 "구분2별 집계" 같은 작은 피벗 요약표는 새 데이터를 넣어도
  자동으로 갱신되지 않습니다 (엑셀에서 피벗 새로고침을 직접 눌러주세요).
- 파일 용량이 커서(서식이 많이 걸려있어서) 엑셀에서 여는 데 시간이 좀 걸릴 수
  있습니다 — 원본 파일도 원래 그랬을 가능성이 높습니다.
