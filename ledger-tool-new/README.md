# ERP 원장 → 신규 워크북 생성 도구

기존 누적 워크북(거래 데이터가 담긴 master) 없이, ERP(이카운트)에서 받은
raw 원장 파일만으로 새 거래내역 워크북을 처음부터 만드는 도구입니다.

`ledger-tool`(누적형)과의 차이:

|  | ledger-tool (누적형) | ledger-tool-new (신규 생성, 이 폴더) |
|---|---|---|
| master 폴더에 넣는 것 | 거래 데이터가 쌓여있는 워크북 | 계정과목표 시트만 있는 양식 (거래 데이터 없음) |
| 이월잔액 행 | 제외 (이미 master에 반영됨) | **포함** (처음 만드는 것이므로 기초잔액 필요) |
| 구분1/구분2 | 살아있는 수식 | 계산된 고정값 |

**왜 master 양식이 그래도 필요한가요?** raw 원장 파일에는 계정코드/계정명만
있고, 그 계정이 "채권"인지 "채무"인지 "자산"인지 같은 구분(구분1/구분2)
정보는 없습니다. 그 구분은 `99.이카운트 계정과목표_HF` 표에만 있어서,
거래 데이터는 없어도 이 표 하나는 필요합니다.

## 이 도구가 하는 일

1. `input_raw/`에 넣은 raw 원장 파일들을 각각 하나의 시트로 만듭니다
   (파일명 = 시트 이름, 예: `HT.xlsx` → `HT` 시트).
2. `master/`에 넣은 양식 파일 안의 계정과목표 시트를 기준으로 구분1·구분2를
   자동으로 채웁니다.
3. 상대구분은 수기로 확인하는 항목이라 공란으로 둡니다.
4. 날짜(B열)는 정렬 가능한 실제 날짜형으로 넣습니다.
5. 계정블록별로 "raw 파일의 합계 = 담은 거래 합계"가 맞는지 자동 검증합니다.

## 폴더 구조

```
ledger-tool-new/
  input_raw/   raw 원장 xlsx를 넣는 곳 (파일명 = 시트명)
  master/      계정과목표 시트만 포함된 양식 파일 1개를 넣는 곳 (아래 "양식 파일 준비" 참고)
  output/      새로 만들어진 워크북이 저장되는 곳
  create_ledger.py   실제 처리 스크립트
  run_mac.command     macOS 더블클릭 실행용
  run_windows.bat     Windows 더블클릭 실행용
```

## 준비 (최초 1회)

`ledger-tool`과 동일합니다 — Python 설치 후 터미널에서:
```
pip3 install openpyxl
```

## 양식 파일 준비 (최초 1회, 또는 계정과목표가 바뀔 때)

기존 누적 워크북(예: `ledger-tool`의 master 파일)을 갖고 계시면 그 안의
`99.이카운트 계정과목표_HF` 시트를 별도 파일로 빼서 `master/` 폴더에 넣으면
됩니다 (다른 시트는 없어도 됩니다, 이 시트 하나만 있으면 됩니다):

1. 누적 워크북을 엑셀로 엽니다.
2. `99.이카운트 계정과목표_HF` 시트 탭을 오른쪽 클릭 → **이동/복사**
3. "받는 통합 문서"를 **(새 통합 문서)**로 선택, "복사본 만들기" 체크 → 확인
4. 새로 뜬 통합 문서를 `계정과목표.xlsx` 같은 이름으로 저장해서 `master/` 폴더에 넣기
   (시트 이름은 반드시 `99.이카운트 계정과목표_HF` 그대로 유지)

이 파일은 실제 회계 데이터라 git에는 올라가지 않으니, 매번 로컬에 준비해두셔야 합니다.

## 사용법

1. `input_raw/`에 raw 원장 파일들을 넣습니다 (여러 회사 한 번에 가능).
2. `master/`에 위에서 준비한 양식 파일 1개를 넣습니다.
3. `run_windows.bat`(Windows) 또는 `run_mac.command`(Mac)를 더블클릭합니다.
4. `output/`에 `신규_거래내역_날짜시간.xlsx` 파일이 생깁니다.
5. 터미널에 뜬 `계정블록 검증: N/N 통과`를 확인하세요.

## 확인하는 방법

- `계정블록 검증`이 전부 통과했는지 먼저 보고, `[불일치]`가 있으면 그 계정만
  raw 파일과 대조해보세요.
- 시트를 열어서 각 계정의 "이월잔액" 행(적요='이월잔액')이 raw 파일의 이월잔액과
  같은 값인지 확인하세요.
- B열(날짜)을 클릭했을 때 오른쪽 정렬되고, 정렬 버튼이 정상 동작하는지 확인하세요.

## 이후 계속 누적하려면

이 도구로 만든 결과 파일을 그대로 `ledger-tool`(누적형) 폴더의 `master/`에
넣고, 다음 기간 raw 파일을 `ledger-tool`의 `input_raw/`에 넣어 이어서
사용하면 됩니다. 단, 구분1/구분2가 여기서는 수식이 아니라 고정값으로
들어가 있다는 점만 참고하세요 (계정과목표가 나중에 바뀌어도 이 파일의
기존 행은 자동으로 갱신되지 않습니다).
