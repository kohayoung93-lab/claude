# ERP 원장 → 빈 시트 채우기 도구

"시트/제목/헤더/계정과목표는 있지만 거래 데이터는 비어있는" master 워크북에,
여러 회사의 raw 원장 파일을 한 번에 채워 넣는 도구입니다.

`ledger-tool`(누적형), `ledger-tool-new`(신규 생성)와의 차이:

|  | ledger-tool | ledger-tool-new | ledger-tool-fill (이 폴더) |
|---|---|---|---|
| master | 데이터가 쌓인 워크북 | 계정과목표 시트만 있는 양식 | **여러 시트 + 계정과목표가 있지만 데이터는 빈 워크북** |
| 채우는 범위 | 전체 컬럼(A~AC) | 전체 컬럼(A~AC) | **A~V열만** (W~AC는 비워둠) |
| 구분1/구분2 | 살아있는 수식 | 계산된 고정값 | **살아있는 수식** (ledger-tool과 동일) |
| 이월잔액 | 제외 | 포함 | 시트가 비어있으면 포함, 이미 데이터가 있으면 제외 (자동 판단) |
| 피벗테이블 | 그대로 유지 | 없음 | **완전히 제거** |

## 이 도구가 하는 일

1. `input_raw/`에 넣은 raw 원장 파일들을 각각 이름이 같은 시트에 채웁니다
   (파일명 = 시트 이름, 예: `HD.xlsx` → `HD` 시트).
2. A~V열(일자-No ~ 상대계정명)은 raw 데이터를 그대로 채웁니다. W열(상대거래처코드)
   ~AC열(비고)은 비워둡니다.
3. Y(잔액2)/Z(구분1)/AA(구분2)는 `ledger-tool`과 동일하게 계정과목표를 참조하는
   살아있는 수식(SUMIFS, INDEX/MATCH)으로 채우고, 값도 미리 계산해 둡니다.
4. 대상 시트가 비어있으면 이월잔액을 기초잔액으로 포함하고, 이미 데이터가 있으면
   (재실행 등) 이미 반영되어 있다고 보고 제외합니다 — 자동으로 판단합니다.
5. 1행(제목 + 차변/대변 합계 수식)과 2행(헤더)은 절대 건드리지 않습니다.
6. master에 있던 피벗테이블과 관련 캐시를 전부 제거합니다 (실제 동작하는 피벗을
   유지할 수 없어서 헷갈리는 잔여물을 남기지 않도록).
7. 계정블록별로 "raw 합계 = 담은 거래 합계"를 자동 검증합니다.

## 폴더 구조

```
ledger-tool-fill/
  input_raw/   raw 원장 xlsx를 넣는 곳 (파일명 = 시트명)
  master/      채울 대상 워크북 1개 (여러 시트 + 계정과목표 포함, 데이터는 없어도 됨)
  output/      결과가 저장되는 곳 (master 원본은 수정되지 않음)
  fill_ledger.py      실제 처리 스크립트
  run_mac.command     macOS 더블클릭 실행용
  run_windows.bat     Windows 더블클릭 실행용
```

## 준비 (최초 1회)

`ledger-tool`과 동일합니다 — Python 설치 후 터미널에서:
```
pip3 install openpyxl
```

## 사용법

1. `input_raw/`에 raw 원장 파일들을 넣습니다 (여러 회사 한 번에 가능, 파일명 =
   채울 시트 이름과 정확히 일치해야 함).
2. `master/`에 채울 대상 워크북 1개를 넣습니다.
3. `run_windows.bat`(Windows) 또는 `run_mac.command`(Mac)를 더블클릭합니다.
4. `output/`에 `{master파일명}_filled_날짜시간.xlsx` 파일이 생깁니다.
5. 터미널에 뜬 `계정블록 검증: N/N 통과`를 확인하세요.

## 확인하는 방법

- `계정블록 검증`이 전부 통과했는지 먼저 보고, `[불일치]`가 있으면 그 계정만
  raw 파일과 대조해보세요.
- 각 시트의 "이월잔액 포함 여부"가 의도한 대로인지 확인하세요 (비어있던 시트는
  포함, 이미 데이터가 있던 시트는 제외).
- 결과 파일을 열어서 W열(상대거래처코드)부터 공란인지, Y/Z/AA열에 값이 채워졌는지
  확인하세요.
- 피벗테이블이 있던 자리(우측 열)에 남아있던 "행 레이블" 같은 잔여 텍스트가
  사라졌는지 확인하세요.
